## Goal

Make the elastic-net + stability-selection pipeline run reliably on *P. evermanni* (Peve) and
*P. tuahiniensis* (Ptua/Ptuh) as well as *A. pulchra* (Apul), **without changing the modelling**.
Each species still gets its own model, trained on its own data.

## What changed

New script `M-multi-species/scripts/26.8-ElasticNet-stabsel-multispecies.R`, a copy of 26.7
(26.7 is left untouched). Every change is tagged `[26.8]` in the code.

| # | Problem in 26.7 | Change in 26.8 |
|---|---|---|
| 1 | `metadata_file` argument ignored; hardcoded relative path, so the script only worked from `M-multi-species/scripts` | Uses the argument; stops with a clear error if the file doesn't exist |
| 2 | Species guessed from miRNA column names only | Optional arg 15 `species_code` (Apul/Peve/Ptuh/Ptua); auto-detect kept as default. Also checks every input file contains that species' samples |
| 3 | Response file had to have a `gene_id` column | `gene_id` dropped only if present |
| 4 | A sample missing from one layer crashed with "undefined columns selected"; `identical()` checks printed nothing | Lists which samples are missing from which layer, and prints the exact exclusion string to use; checks are enforced |
| 5 | Predictor type guessed from ID prefix (`FUN` = methylation), so all Peve/Ptua methylation features were labelled "Other" | Type assigned from the input layer each feature came from |
| 6 | `n_cores > 1` crashes on Windows (`mclapply` can't fork) | Forced to 1 core on Windows, with a warning |
| 7 | Input paths were printed before the log file opened, so saved logs had no record of inputs | All arguments and paths written to the log |

## Verification

Ran 26.8 on exactly the Step 0 inputs and arguments (deliberately from the repo root, which 26.7
could not do), then compared every output CSV against the 26.7 baseline with
`E5_runs/compare_outputs.R`:

**All 9 output CSVs are byte-for-byte identical.** The new layer-based predictor labels agree with
26.7's prefix labels on all 29,829 Apul features (as expected; the fix matters only for Peve/Ptua).

  the other 5 exclusions isn't recorded. Kept for comparability with 26.6, pending an explanation.

## Known issues (not changed yet)

- `_75pct` methylation files contain missing values (Peve 38k cells, Ptua 16k). Any methylation feature
  with a missing value is silently discarded, via NA rows created by the low-count filter. This explains
  the ~9,000 "problematic predictors" removed in the 26.6 Peve/Ptuh runs.
- Stability selection: one 80% subsample per iteration, but logs claim "2 × n complementary-pair fits".
- Inner `cv.glmnet` folds are not colony-grouped; preprocessing uses all samples.
- R exits with a Windows crash code after finishing; outputs are complete.
